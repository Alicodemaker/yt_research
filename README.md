# yt-research

An Agent Skill for Claude Code and Cowork that looks up YouTube channels and videos and returns JSON. It can list a channel's latest or most popular videos, and get one video's metadata, chapters and transcript.

Work in progress. See [PLAN.md](PLAN.md). Setup and install steps come with step 6.

- **Rules:** [AGENTS.md](AGENTS.md) is the single rules file. `CLAUDE.md` only points to it.
- **Tests:** `pip install pytest`, then `pytest -q`. They run offline.
