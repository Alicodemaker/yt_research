## Decisions made by the user

- **.dk domains:** always Simply.com, never Hostinger. Hostinger's .dk guide is outdated, because nobody can manage a .dk at Punktum directly any more.
- **Client email:** a real Simply mailbox added as an account in the Gmail app, Outlook or Apple Mail. No external forwarding (Simply advises against it) and no Gmail "Send as" (it ends January 2027). Cloudflare Email Routing is for receive-only addresses only.
- **House rule:** rich-text HTML from Pages CMS rendered with `set:html` only from trusted editors.

## Gotchas

- **The WebFetch tool doesn't see hosts added to the allowlist mid-session.** `curl` from Bash does. Cloudflare docs give markdown at `<path>/index.md`, plus `llms.txt` and `/.well-known/search?q=`. GitHub docs: `docs.github.com/api/article/body?pathname=/en/...`. MDN: `<page>/index.json`.
- **Cloudflare Email Routing moved** under `developers.cloudflare.com/email-service/`.
- **Notion `update_content` misses** on text where Notion auto-linked a domain (e.g. `[Simply.com](http://Simply.com)`). The guide page is about 185k characters: fetch it to a file and grep it with `jq -r .text`.
